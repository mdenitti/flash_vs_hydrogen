# Ultrarealistic Globe

Interactive 3D Earth built with Three.js, with 10 procedurally modelled landmarks, free-flight, orbit mode, fly-to animations, day/night lighting and a speed control.

## Run

```bash
npm start
```

Then open <http://localhost:3000>.

Use a different port with:

```bash
PORT=8080 npm start
```

> Do not open `index.html` directly with `file://` — ES modules and the import map only work over HTTP.
